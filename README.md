# קלטות מהעבר

משחק סרטונים למסיבת רווקים: רמזים מתהפכים על המסך, החברים מנחשים מהטלפון, והחתן מנסה לזהות מי מדבר אליו.

- `index.html` — המסך שמקרינים, כולל עריכת המשחק. התמונות והסרטונים נשמרים בדפדפן של המחשב המקרין בלבד ולא עולים לכאן.
- `play.html` — הדף שנפתח בטלפון מה-QR.
- `lib/` — ספריות: mqtt.js (MIT), qrcode-generator (MIT), ושכבת התקשורת של המשחק.

הניחושים עוברים בין הטלפונים למסך דרך שרתי MQTT ציבוריים וחינמיים (HiveMQ ו-EMQX).
